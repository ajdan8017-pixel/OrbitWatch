## 1. Именование (Naming Conventions)
- [x] Переменные и свойства объектов в нотации `camelCase` (например, `satelliteItem`, `declinationRad`, `subSolarLng`).
- [x] Функции и методы в нотации `camelCase` (например, `calculateSatellitePosition`, `calculateTLEChecksum`, `getSatrec`).
- [x] Классы, интерфейсы и React-компоненты в нотации `PascalCase` (например, `SpaceScene`, `OrbitWatchError`, `CelestialPositions`).
- [x] Именованные константы верхнего уровня в нотации `UPPER_SNAKE_CASE` (например, `EARTH_RADIUS_KM`, `SUN_DISTANCE_UNITS`, `TLE_LINE_LENGTH`).
- [x] Имена файлов утилит и сервисов в `camelCase`, компонентов в `PascalCase`, документации в `kebab-case`.
- [x] Имена переменных осмысленные, отсутствие неинформативных идентификаторов (`x`, `a`, `tmp` заменены на семантические).

- [x] Длина функций: вычислительные функции декомпозированы и не превышают 50–60 строк.
