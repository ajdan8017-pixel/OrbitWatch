## 1. Введение

**OrbitWatch** — это интерактивная геоинформационная 3D-система астродинамического мониторинга, предназначенная для отслеживания космических аппаратов и орбитальных группировок на околоземной орбите в режиме реального времени.

### Основные возможности:
- Точный физический расчёт орбит по математической модели **SGP4/SDP4** на основе двухстрочных наборов элементов NORAD TLE.
- Фотореалистичная 3D-сцена земного шара с суточным вращением, процедурными текстурами дня/ночи, облаками и атмосферным свечением Рэлея.
- Отображение текущего положения Солнца и фаз Луны в зависимости от выбранной временной метки.
- Мониторинг ключевых группировок: МКС, созвездие Starlink, навигационные системы GPS/ГЛОНАСС, гидрометеорологические и научные аппараты.
- Симуляция хода времени с ускорением до 60x для исследования эволюции витков траектории.
- Модуль интерактивных исторических космических миссий (Восток-1, Аполлон-11, МКС, Вояджер-1).

## 2. Роли пользователей и сценарии использования

| Роль пользователя | Цель работы в системе | Ключевые используемые функции |
|---|---|---|
| **Радиолюбитель / Астроном-наблюдатель** | Прогнозирование времени пролёта аппаратов над горизонтом, подготовка сеансов радиосвязи через ретрансляторы | Поиск по NORAD ID, расчёт траектории витка, инспекция подспутниковой точки (широта/долгота), слежение за аппаратом |

## 3. Начало работы с приложением

### 3.1. Системные требования
- **Устройство:** Персональный компьютер, ноутбук, планшет или смартфон.
- **Браузер:** Google Chrome 100+, Mozilla Firefox 105+, Apple Safari 16+, Microsoft Edge 100+ с поддержкой **WebGL 2.0**.
- **Устройства ввода:** Мышь с колесом прокрутки, тачпад или сенсорный экран (поддержка Pinch-to-zoom).
- **Подключение к сети:** Не требуется для базовой работы (встроен автономный offline-каталог TLE).

### 3.2. Запуск приложения
1. Откройте веб-браузер.
2. Перейдите по адресу развёрнутого приложения: `http://localhost:3000` (локально) или по ссылке на облачный хостинг.
3. Дождитесь первичной инициализации Three.js сцены (обычно 1–1.5 секунды). На экране отобразится интерактивный 3D-глобус Земли с мерцающими маркерами спутников.

## 4. Обзор элементов интерфейса

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [🛰 OrbitWatch] [ Категории: Станции | Starlink | GPS ] [🔊 Звук] [ Миссии ]│ ← Header
├─────────────┬─────────────────────────────────────────────────┬─────────────┤
│             │                                                 │             │
│ [Фильтры]   │                                                 │ [Карточка   │
│             │              3D ГЛОБУС ЗЕМЛИ                    │  спутника:  │
│ [Поиск...]  │             (Three.js WebGL)                    │  МКС        │
│             │                                                 │  Скорость:  │
│ [Список     │                                                 │  7.66 км/с  │
│  спутников] │                                                 │  Высота:    │
│             │                                                 │  418 км]    │
│             │                                                 │             │
├─────────────┴─────────────────────────────────────────────────┴─────────────┤
│ [ ⏸ Пауза ] [ 1x ] [ 5x ] [ 10x ] [ 60x ]  [ 🕒 07.10.2026 12:00:00 UTC ]    │ ← Time Bar
└─────────────────────────────────────────────────────────────────────────────┘
```

1. **Верхняя панель (Header):** Логотип, счётчик активных объектов, переключатель звуковых эффектов, кнопка каталога миссий.
2. **Центральная 3D-сцена:** Интерактивное космическое пространство, планета Земля, звёздное небо, Солнце и орбитальные аппараты.
3. **Левая панель (Каталог и фильтры):** Быстрый выбор группировок и кнопка вызова бокового списка спутников (Drawer).
4. **Правая карточка аппарата (Telemetry Card):** Подробная телеметрия выбранного спутника с расчётом скорости и высоты.
5. **Нижний контроллер времени (Time Controller):** Управление симуляцией, ускорение хода времени и календарная дата.

## 5. Пошаговые инструкции по основным функциям

### 5.1. Управление камерой в 3D-пространстве
- **Вращение глобуса:** Зажмите **левую кнопку мыши (ЛКМ)** и перемещайте курсор (на тачскрине — свайп одним пальцем).
- **Масштабирование (Зум):** Вращайте **колесо мыши** от себя (приближение) или к себе (отдаление). На смартфонах — жест сведения/разведения двух пальцев (Pinch-to-zoom).
- **Панорамирование:** Зажмите **правую кнопку мыши (ПКМ)** или две клавиши мыши одновременно для смещения центра обзора.

### 5.2. Выбор и отслеживание спутника
1. Наведите курсор на любой цветной маркер на орбите — появится всплывающая подсказка с именем аппарата и высотой.
2. Кликните **ЛКМ** по маркеру:
   - Камера плавно сфокусируется на объекте.
   - В пространстве вокруг Земли прорисуется замкнутая **3D-траектория полного витка орбиты**.
   - Справа откроется **Карточка телеметрии**.
3. Чтобы включить режим непрерывного сопровождения аппарата камерой при движении, нажмите переключатель **«Следить за спутником»** в карточке.

### 5.3. Фильтрация и поиск аппаратов в каталоге
1. **Быстрые фильтры группировок:** Нажмите на кнопки в верхней части экрана:
   - 🟡 **Станции (Stations):** Обитаемые комплексы (МКС, Тяньгун).
   - 🔵 **Starlink:** Коммерческая телекоммуникационная группировка SpaceX.
   - 🟢 **Навигация (Navigation):** Спутники позиционирования GPS, ГЛОНАСС, Galileo.
   - 🟣 **Погода (Weather):** Метеорологические аппараты NOAA и Метеор-М.
   - 🔴 **Наука (Science):** Орбитальные телескопы Хаббл и Уэбб.
2. **Поиск по названию или номеру NORAD:**
   - Нажмите кнопку **«Список спутников»** на левой панели.
   - В поле поиска введите часть имени (например, `ISS` или `NOAA`) либо 5-значный номер NORAD (например, `25544`).
   - Кликните по найденному элементу в списке для мгновенного перехода к нему на 3D-глобусе.

### 5.4. Управление ходом времени (Time Warp)
- Нажмите **«Пауза» [⏸]**, чтобы зафиксировать мгновенное положение всех космических аппаратов на текущую секунду.
- Выберите коэффициенты ускорения: **1x** (реальное время), **5x**, **10x** или **60x** (одна секунда равна одной минуте). При ускорении 60x вы сможете наблюдать полный виток МКС вокруг Земли всего за 1.5 минуты.
- Нажмите кнопку **«Сейчас» (Realtime)** для мгновенной синхронизации симуляции с точным мировым временем UTC.

### 5.5. Просмотр исторических космических миссий
1. В верхнем меню нажмите кнопку **«Миссии»**.
2. В открывшемся модальном окне выберите историческое событие:
   - 🚀 **Восток-1 (1961):** Первый полет человека в космос (Ю. А. Гагарин).
   - 🌕 **Аполлон-11 (1969):** Первая высадка людей на Луну.
   - 🛰 **МКС (1998 — н.в.):** Крупнейший международный орбитальный научный дом.
   - 🌌 **Вояджер-1 (1977):** Самый далёкий рукотворный объект в межзвёздном пространстве.
3. Ознакомьтесь с хронологией, параметрами запуска, архивными фактами и 3D-параметрами полета.

## 6. Часто задаваемые вопросы (FAQ)

**В: Откуда берутся орбитальные координаты спутников?**  
О: Приложение использует официальные наборы двухстрочных элементов NORAD TLE, получаемые через прокси-сервер с портала CelesTrak. Математический движок `satellite.js` вычисляет координаты по аналитической теории SGP4 с учетом сплюснутости Земли ($J_2$) и сопротивления верхней атмосферы.

**В: Работает ли OrbitWatch без подключения к интернету?**  
О: Да. В систему встроен автономный каталог `FALLBACK_TLE_DATA`, содержащий точные орбиты ключевых аппаратов, а также механизм безопасного сохранения в `LocalStorage`. Приложение полностью сохраняет интерактивность в оффлайн-режиме.

**В: Почему спутник не падает на Землю? Какая у него скорость?**  
О: Для спутников на низкой околоземной орбите (высота 400–450 км) скорость составляет около **7.66 км/с** (первая космическая скорость). Карточка телеметрии рассчитывает скорость аппарата в реальном времени.

**В: Что делать, если на слабом ноутбуке снижается частота кадров (FPS)?**  
О: Рекомендуется:
1. Выключить эффект свечения Bloom (кнопка в панели управления).
2. Выбрать фильтр одной конкретной категории вместо отображения всех аппаратов одновременно.
3. Убедиться, что в настройках браузера включено «Аппаратное ускорение графики».
