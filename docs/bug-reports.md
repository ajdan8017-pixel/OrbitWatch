## Детальные баг-репорты

### BR-01: Необработанное исключение при переполнении квоты LocalStorage
- **Связанный тест-кейс:** TC-16 (TS-08)
- **Приоритет:** Высокий
- **Серьезность:** Major
- **Тестировщик:** Сидоров А.В.
- **Исполнитель:** Иванов И.И.
- **Шаги воспроизведения:**
  1. Открыть консоль DevTools (`F12`).
  2. Заполнить `localStorage` строковыми данными до упора:
     ```javascript
     try { for (let i = 0; i < 20; i++) localStorage.setItem('flood_' + i, 'X'.repeat(500000)); } catch (e) {}
     ```
  3. Обновить страницу OrbitWatch для сохранения свежего TLE-кэша.
- **Ожидаемый результат:** Метод `safeLocalStorageSet()` перехватывает `QuotaExceededError`, удаляет временный мусор и сохраняет критические данные в сессионную память без падения.
- **Фактический результат:** Вспомогательный модуль кэширования вызывал прямой `localStorage.setItem()` минуя защищенную обертку, что приводило к `DOMException: QuotaExceededError`.
- **Причина:** В одной из веток сервиса `tleService.ts` сохранение вызывалось напрямую через `localStorage` вместо утилиты `safeLocalStorageSetItem()`.
- **Решение:** Все вызовы `localStorage.setItem` заменены на отказоустойчивую функцию `safeLocalStorageSetItem()`.
- **Статус:** ✅ Исправлено и верифицировано.

### BR-02: Наложение всплывающей карточки спутника на панель Time Warp на мобильных устройствах
- **Связанный тест-кейс:** TC-19 (TS-11)
- **Приоритет:** Средний
- **Серьезность:** Minor
- **Тестировщик:** Петров Д.С.
- **Исполнитель:** Петров Д.С.
- **Шаги воспроизведения:**
  1. В Chrome DevTools включить Device Toolbar (разрешение 360x640, мобильный телефон).
  2. Нажать на любой спутник для открытия подробной инфо-карточки.
  3. Попытаться переключить скорость симуляции (кнопки 1x, 5x, 60x).
- **Ожидаемый результат:** Нижняя панель времени и правая карточка спутника не перекрывают интерактивные кнопки друг друга.
- **Фактический результат:** Карточка спутника в мобильной ориентации перекрывала правые кнопки панели времени, блокируя нажатие кнопки «Пауза».
- **Причина:** Фиксированное позиционирование `bottom-4` и отсутствие отступа снизу на мобильных экранах (`max-w-sm`).
- **Решение:** Добавлен адаптивный отступ `bottom-24 sm:bottom-6` и оптимизирована высота карточки со скроллом для экранов меньше 640px.
- **Статус:** ✅ Исправлено и верифицировано.

### BR-03: Утечка ресурсов WebGL при скрытии вкладки браузера
- **Связанный тест-кейс:** TC-18 (TS-10)
- **Приоритет:** Высокий
- **Серьезность:** Major
- **Тестировщик:** Сидоров А.В.
- **Исполнитель:** Иванов И.И.
- **Шаги воспроизведения:**
  1. Открыть приложение в фоновой вкладке.
  2. Переключиться на другую вкладку на 10 минут.
  3. Вернуться на вкладку OrbitWatch и оценить загрузку GPU и FPS.
- **Ожидаемый результат:** Браузер снижает частоту рендера, утечка контекста отсутствует, сцена плавно возобновляется.
- **Фактический результат:** На некоторых видеокартах при уходе в энергосбережение WebGL контекст терялся, но обработчик `requestAnimationFrame` продолжал слать команды в недействительный контекст.
- **Причина:** Отсутствовала проверка `document.hidden` и флага потери контекста в RAF-цикле.
- **Решение:** Внедрен слушатель события `visibilitychange`: при скрытии вкладки цикл симуляции встает на микро-паузу, сберегая батарею и видеопамять.
- **Статус:** ✅ Исправлено и верифицировано.

### BR-04: Микро-задержка (120 мс) при первичной компиляции CanvasTexture для спрайтов
- **Сценарий:** TC-04 (TS-02)
- **Приоритет:** Низкий
- **Серьезность:** Trivial
- **Тестировщик:** Иванов И.И.
- **Исполнитель:** Иванов И.И.
- **Шаги воспроизведения:**
  1. Очистить кэш браузера и загрузить приложение с 200+ спутниками.
  2. Замерить время между разбором TLE и появлением спрайтов в сцене.
- **Ожидаемый результат:** Иконки генерируются плавно без просадки первого кадра.
- **Фактический результат:** Единовременная синхронная отрисовка 200 canvas-элементов на CPU вызывала секундный лаг главного потока.
- **Причина:** Генерация CanvasTexture происходила поштучно для каждого отдельного спутника.
- **Решение:** Внедрен глобальный атлас/пул текстур: текстура генерируется ровно один раз на категорию аппарата (5 мастер-текстур), а спутники используют общие экземпляры `THREE.SpriteMaterial`.
- **Статус:** ✅ Исправлено и верифицировано.
