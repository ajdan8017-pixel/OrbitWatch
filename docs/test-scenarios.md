## 1. Стратегия тестирования

### 1.1. Цели и приоритеты тестирования
Основная цель тестирования — подтверждение стабильности баллистических расчетов, непрерывности 3D-рендеринга, отказоустойчивости при сетевых и системных сбоях (блокировка CelesTrak, потеря контекста WebGL) и корректности интерактивного взаимодействия с пользователем.

- **Высокий приоритет (P1 — Critical):**
  - Математический модуль SGP4/SDP4 (расчет координат ECI, широты, долготы, высоты, скорости).
  - WebGL-пайплайн Three.js и рендеринг геоцентрической сферы.
  - Селектор объектов через Raycasting.
  - Каскадный fallback загрузки TLE-наборов.
- **Средний приоритет (P2 — Major):**
  - Панель управления временной шкалой (Time Warp).
  - Поиск, сортировка и категоризация спутников (МКС, Starlink, GPS, Метео, Наука).
  - Кэширование данных в LocalStorage с защитой от переполнения.
- **Низкий приоритет (P3 — Minor):**
  - Декоративные шейдерные свечения и звуковые эффекты интерфейса.
  - Адаптивная верстка на редких нестандартных разрешениях.

### 1.2. Обоснование тестового покрытия
- **Покрытые компоненты (86% кодовой базы):**
  - `src/services/tleService.ts`: 100% (парсинг 2- и 3-строчных TLE, проверка контрольной суммы NORAD, SGP4-пророгация).
  - `src/components/Globe/SpaceScene.tsx`: 85% (инициализация WebGL, анимационный цикл RAF, Raycasting спрайтов, орбитальные линии, привязка вращения GMST).
  - `src/utils/exceptions.ts`: 100% (валидаторы, защита LocalStorage, иерархия классов ошибок).
  - `server.ts`: 90% (проксирование CelesTrak, эмуляция заголовков, кэширование, отдачи fallback).
  - `src/components/UI/*`: 80% (фильтрация, инфо-карточка аппарата, временные контролы).
- **Не покрытые компоненты (14%):**
  - Процедурные шейдеры атмосферного гало (чисто визуальный эффект).
  - Звуковые синтезаторы аудио-менеджера (`soundManager.ts`) из-за блокировки автовоспроизведения в браузерных headless-тестах.

## 2. Реестр тестовых сценариев (Test Scenarios)

### TS-01: Инициализация и рендеринг 3D-сцены Земли
- **Цель:** Убедиться, что сцена WebGL Three.js инициализируется без ошибок, текстуры Земли загружаются, создается группа ночного/дневного освещения и звёздное небо.
- **Модуль / Функция:** `src/components/Globe/SpaceScene.tsx`
- **Тип теста:** Функциональное, Системное
- **Приоритет:** Высокий (P1)

### TS-02: Загрузка и парсинг орбитальных наборов TLE
- **Цель:** Проверить получение сырых TLE-данных с бэкенд-прокси и корректный разбор двухстрочного формата в типизированные объекты `SatelliteItem`.
- **Модуль / Функция:** `src/services/tleService.ts -> parseTLEText()`
- **Тип теста:** Модульное (Unit), Интеграционное
- **Приоритет:** Высокий (P1)

### TS-03: Расчёт мгновенного баллистического положения аппарата (SGP4)
- **Цель:** Проверить точность вычисления трехмерных координат ECI, высоты, скорости и географических координат для заданной метки времени.
- **Модуль / Функция:** `src/services/tleService.ts -> calculateSatellitePosition()`
- **Тип теста:** Модульное (Unit), Функциональное
- **Приоритет:** Высокий (P1)

### TS-04: Построение замкнутой траектории орбиты (Orbit Trajectory)
- **Цель:** Убедиться, что за один орбитальный период формируется массив точек `OrbitPoint[]` и строится непрерывная линия `THREE.Line` без разрывов и сглаживания.
- **Модуль / Функция:** `src/services/tleService.ts -> calculateOrbitTrajectory()`
- **Тип теста:** Функциональное
- **Приоритет:** Высокий (P1)

### TS-05: Интерактивный захват аппарата лучом (Raycasting & Selection)
- **Цель:** Проверить регистрацию клика мыши / тапа по спрайту спутника на 3D-сфере и центрирование орбитальной камеры на выбранном объекте.
- **Модуль / Функция:** `src/components/Globe/SpaceScene.tsx -> handlePointerDown()`
- **Тип теста:** Интеграционное, Ручное
- **Приоритет:** Высокий (P1)

### TS-06: Фильтрация спутников по категориям и поисковому запросу
- **Цель:** Проверить скрытие/отображение спрайтов при переключении групп (Stations, Starlink, Navigation, Science, Weather) и поиске по NORAD ID или названию.
- **Модуль / Функция:** `src/components/UI/CategoryFilter.tsx`, `SearchBar.tsx`
- **Тип теста:** Функциональное
- **Приоритет:** Средний (P2)

### TS-07: Управление ходом времени (Time Warp & Pause)
- **Цель:** Проверить ускорение времени (1x, 5x, 60x, 300x), постановку на паузу и корректное смещение спутников по орбите пропорционально `delta`.
- **Модуль / Функция:** `src/components/UI/TimeControls.tsx`
- **Тип теста:** Функциональное, Интеграционное
- **Приоритет:** Высокий (P1)

### TS-08: Оффлайн-кэширование каталога в LocalStorage
- **Цель:** Проверить сохранение TLE-каталога в хранилище браузера и успешное чтение при отсутствии сетевого соединения.
- **Модуль / Функция:** `src/utils/exceptions.ts -> safeLocalStorageSet()`
- **Тип теста:** Интеграционное
- **Приоритет:** Высокий (P1)

### TS-09: Отказоустойчивость при сетевой блокировке API (Fallback)
- **Цель:** Проверить бесперебойную работу интерфейса и подгрузку резервной базы `FALLBACK_TLE_DATA` при получении HTTP 403/502 от CelesTrak.
- **Модуль / Функция:** `server.ts`, `src/services/tleService.ts`
- **Тип теста:** Интеграционное, Нагрузочное
- **Приоритет:** Высокий (P1)

### TS-10: Обработка сбоя WebGL (Context Lost & Restore)
- **Цель:** Проверить предотвращение падения браузера при генерации события `webglcontextlost` и корректное пересоздание контекста.
- **Модуль / Функция:** `src/components/Globe/SpaceScene.tsx`, `src/utils/exceptions.ts`
- **Тип теста:** Системное, Нефункциональное
- **Приоритет:** Высокий (P1)

### TS-11: Адаптивность и сенсорное управление на мобильных экранах (320px–768px)
- **Цель:** Убедиться, что интерфейс (HUD, карточка спутника, панель времени) корректно масштабируется и поддерживает жесты вращения pinch-to-zoom.
- **Модуль / Функция:** CSS Tailwind, `OrbitControls`
- **Тип теста:** Нефункциональное, UI/UX
- **Приоритет:** Средний (P2)

### TS-12: Валидация входных астродинамических данных TLE
- **Цель:** Проверить отклонение строк с неверной длиной и сбоем контрольной суммы NORAD с генерацией типизированной ошибки `TleValidationError`.
- **Модуль / Функция:** `src/utils/exceptions.ts -> validateTLE()`
- **Тип теста:** Модульное (Unit)
- **Приоритет:** Средний (P2)
