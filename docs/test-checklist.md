## 2. Чек-лист тестирования

### 2.1. Функциональное тестирование (Баллистика и 3D-сцена)
- [x] **CH-01:** Холст WebGL инициализируется без артефактов, сфера Земли отрендерена с текстурами суши и океанов.
- [x] **CH-02:** Вращение сферы Земли строго синхронизировано со звёздным гринвичским временем GMST (`satellite.gstime()`).
- [x] **CH-03:** На орбитах отображаются спрайты 5 категорий спутников (МКС — станция, Starlink — ромб, GPS/ГЛОНАСС — треугольник, Наука — звезда, Метео).
- [x] **CH-04:** Клик мыши по спутнику регистрируется Raycaster'ом с первого раза (хитбокс откалиброван).
- [x] **CH-05:** При выборе спутника вокруг него появляется пульсирующее свечение и строится замкнутый эллипс орбиты за 1 виток.
- [x] **CH-06:** За летящим аппаратом строится затухающий градиентный шлейф (trail) из 50 предыдущих позиций.
- [x] **CH-07:** В правой панели отображаются корректная высота (МКС ~418 км), орбитальная скорость (~7.66 км/с), наклонение и страна запуска.
- [x] **CH-08:** Поиск фильтрует спутники в реальном времени по названию и NORAD ID (например, «ISS», «25544», «TIANGONG»).
- [x] **CH-09:** Фильтр категорий скрывает и показывает соответствующие группировки без лагов интерфейса.
- [x] **CH-10:** Панель Time Warp корректно ускоряет симуляцию (1x, 5x, 60x, 300x) и ставит ход времени на паузу.

### 2.2. Нефункциональное тестирование (Производительность и верстка)
- [x] **CH-11:** Время холодного старта приложения до первого кадра составляет менее 1.5 секунд (факт: 1.15 с).
- [x] **CH-12:** Частота кадров (FPS) стабильно держится на уровне 60 FPS при 200+ объектах на сцене.
- [x] **CH-13:** В консоли браузера Chrome DevTools отсутствуют критические ошибки `Uncaught TypeError` или `Uncaught ReferenceError`.
- [x] **CH-14:** Интерфейс корректно адаптируется под мобильные экраны шириной от 320px до 768px (HUD не перекрывает 3D-сцену).
- [x] **CH-15:** Сенсорное управление на тачскринах поддерживает pinch-to-zoom и вращение сферы двумя пальцами.
- [x] **CH-16:** Потребление оперативной памяти браузера (JS Heap) не превышает 100 МБ в установившемся режиме (факт: 84.5 МБ).

### 2.3. Обработка исключительных ситуаций и отказоустойчивость
- [x] **CH-17:** При блокировке CelesTrak (HTTP 403 / CORS) бэкенд и фронтенд бесшовно переключаются на встроенную базу `FALLBACK_TLE_DATA`.
- [x] **CH-18:** При наличии поврежденной строки TLE с неверной контрольной суммой выбрасывается `TleValidationError`, битая запись отбраковывается, а остальные 99% каталога загружаются штатно.
- [x] **CH-19:** При искусственной потере контекста WebGL (`webglcontextlost`) приложение не падает в белый экран, перехватывает событие и восстанавливает рендеринг по `webglcontextrestored`.
- [x] **CH-20:** При переполнении квоты LocalStorage (5 МБ) перехватывается исключение `QuotaExceededError`, старый кэш очищается, данные сохраняются в in-memory сессию.
- [x] **CH-21:** При клике в пустое космическое пространство фокус плавно сбрасывается на центр Земли `(0, 0, 0)`.
- [x] **CH-22:** При вводе несуществующего поискового запроса выводится аккуратное сообщение «Спутники не найдены» без сбоя списков.
