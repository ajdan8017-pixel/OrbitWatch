**OrbitWatch** — интерактивное fullstack веб-приложение для 3D-визуализации космических аппаратов и орбитальных группировок (МКС, созвездие Starlink, GPS, ГЛОНАСС, научные телескопы) в реальном времени с точным расчётом баллистических траекторий по стандарту **NORAD SGP4/SDP4**.

---

## 🛰 Возможности системы

- **Интерактивный 3D-глобус Земли:** фотореалистичная модель с суточным вращением, процедурными текстурами дня/ночи (городские огни), облачным слоем и рэлеевским атмосферным свечением.
- **Высокоточная баллистика SGP4:** расчет текущих геоцентрических координат (ECI), высоты орбиты, первой космической скорости (~7.66 км/с) и подспутниковой точки (широта/долгота).
- **Орбитальные траектории:** мгновенная генерация замкнутых 3D-витков траектории для выбранного спутника за полный период обращения.
- **Группировки и каталог:** фильтрация по категориям (Обитаемые станции, Starlink, Навигация, Метео, Наука) и мгновенный поиск по имени или номеру NORAD ID.
- **Симуляция времени (Time Warp):** управление скоростью хода времени (пауза, 1x, 5x, 10x, 60x) и точный расчет положения Солнца и фаз Луны.
- **Исторические космические миссии:** интерактивный путеводитель по легендарным миссиям (Восток-1, Аполлон-11, МКС, Вояджер-1).
- **Отказоустойчивость:** защищённый кэш `LocalStorage` с обработкой переполнения дисковой квоты и встроенная автономная база TLE (`FALLBACK_TLE_DATA`).

---

## 📦 Стек используемых технологий

- **Клиентская часть:** React 19, TypeScript, Vite 8, Tailwind CSS v4, Motion (Framer Motion), Lucide React.
- **3D-графика и физика:** Three.js (r186), OrbitControls, EffectComposer, UnrealBloomPass, `satellite.js` (SGP4/SDP4).
- **Серверная часть:** Node.js, Express, `tsx`, отказоустойчивый кэширующий шлюз к CelesTrak.
- **Тестирование и контроль качества:** Vitest v5 (22 unit-теста), GitHub Actions CI, TypeScript compiler (`tsc --noEmit`).

## 🚀 Быстрый старт на localhost

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/chayan-shinin/orbitwatch.git
cd orbitwatch

# Установка зависимостей
npm install
```

### 2. Запуск сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере:  
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🛠 Доступные команды (NPM Scripts)

| Команда | Назначение |
|---|---|
| `npm run dev` | Запуск fullstack-сервера разработки (Express + Vite HMR) на `http://localhost:3000` |
| `npm run dev:vite` | Запуск только клиентского Vite-сервера (без backend-прокси) |
| `npm test` | Запуск набора из 22 автоматических unit-тестов Vitest |
| `npm run build` | Сборка клиентского SPA (`dist/`) и сервера через `esbuild` для продакшена |
| `npm run start` | Запуск скомпилированной production-сборки (`dist/server.cjs`) |
| `npm run preview` | Локальный просмотр скомпилированного продакшен-бандла Vite |
| `npm run lint` | Статическая проверка строгой типизации TypeScript (`tsc --noEmit`) |
| `npm run clean` | Очистка папки сборки `dist/` |
