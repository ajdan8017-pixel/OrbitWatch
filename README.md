# OrbitWatch — 3D Космический Трекер

Интерактивное веб-приложение для 3D-визуализации космических аппаратов и орбитальных группировок (МКС, Starlink, GPS, ГЛОНАСС, научные спутники) в реальном времени с точным расчётом баллистических траекторий по TLE-наборам (SGP4/SDP4).

---

## 🚀 Быстрый запуск на localhost

### 1. Системные требования
- **Node.js** версии **v18.0.0** или новее (рекомендуется v20+)
- **npm** (v9+) или **pnpm** / **yarn** / **bun**

### 2. Клонирование и установка зависимостей
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd orbitwatch

# Установка всех зависимостей проекта
npm install
```

### 3. Настройка переменных окружения (опционально)
Скопируйте пример файла окружения:
```bash
cp .env.example .env
```
*(Опционально)* Если вы хотите включить генерацию расширенных аналитических справок по спутникам через нейросеть Gemini, укажите ваш ключ в файле `.env`:
```env
GEMINI_API_KEY=ваш_ключ_api
```
*Приложение полностью автономно и работает даже без API-ключа (базовые данные, баллистический расчёт SGP4, фильтры и каталог функционируют без ограничений).*

### 4. Запуск локального сервера разработки
```bash
npm run dev
```
После запуска откройте в браузере:  
👉 **[http://localhost:3000](http://localhost:3000)**

---

## 🛠 Доступные команды (NPM Scripts)

| Команда | Назначение |
|---|---|
| `npm run dev` | Запуск fullstack-сервера разработки (Express + Vite HMR) на `http://localhost:3000` |
| `npm run dev:vite` | Запуск только клиентского Vite-сервера (без backend-прокси) |
| `npm run build` | Сборка клиентского SPA (`dist/`) и сервера через `esbuild` для продакшена |
| `npm run start` | Запуск готовой production-сборки (`dist/server.cjs`) |
| `npm run preview` | Локальный просмотр продакшен-бандла Vite |
| `npm run lint` | Проверка типизации TypeScript (`tsc --noEmit`) |
| `npm run clean` | Очистка папки сборки `dist/` |

## 📦 Стек используемых технологий

- **Фронтенд:** React 19, TypeScript, Vite, Tailwind CSS v4, Motion (Framer Motion), Lucide React.
- **3D-графика и расчёты:** Three.js (WebGL 3D-сцена Земли и орбитальных объектов), `satellite.js` (математический пророгатор SGP4/SDP4, ECI -> Geodetic преобразования).
- **Бэкенд:** Node.js, Express, `tsx` (быстрый запуск TypeScript), кэширующий прокси к CelesTrak и SpaceX API.
