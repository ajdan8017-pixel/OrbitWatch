## [1.0.0] — 2026-10-06 (Официальный релиз MVP)

### 🚀 Добавлено (Added)
- **3D-визуализация космического пространства:**
  - Интерактивный фотореалистичный 3D-глобус Земли на базе Three.js (r186) с поддержкой текстур дня, ночи (городские огни) и облачного слоя.
  - Процедурный шейдер атмосферного рассеяния Рэлея (Atmospheric Glow).
  - Космическое окружение со звёздным полем и эффектом свечения звезд (`UnrealBloomPass`).
- **Баллистический расчет орбит (SGP4/SDP4):**
  - Математический пророгатор орбит на базе `satellite.js` для предсказания трехмерных координат аппаратов в реальном времени.
  - Преобразование небесных геоцентрических координат ECI в трёхмерное пространство Three.js и геодезические координаты (широта, долгота, высота).
  - Расчет траектории витка с замыканием петли орбиты за один виток обращения аппарата.
  - Расчет 1-й космической скорости и геоцентрического вектора скорости.
- **Орбитальный каталог и группировки:**
  - Поддержка ключевых группировок: Обитаемые станции (МКС, Тяньгун), Мега-созвездие Starlink, Навигационные системы (GPS, ГЛОНАСС, Galileo), Метеоспутники (NOAA, Метеор), Научные миссии (Хаббл, Джеймс Уэбб).
  - Встроенный автономный offline-каталог `FALLBACK_TLE_DATA` на случай отсутствия сети.
- **Интерактивный пользовательский интерфейс (UI):**
  - Панель фильтрации по категориям с цветовой дифференциацией орбит.
  - Боковая панель (Drawer) с мгновенным поиском по названию и номеру NORAD.
  - Детализированная карточка спутника с астродинамическими параметрами (наклонение, период, апогей, перигей, телеметрия).
  - Интерактивный контроллер времени с перемоткой: пауза, 1x, 5x, 10x, 60x и возврат к текущему времени UTC.
  - Расчет астрономического положения Солнца и Луны в зависимости от выбранного времени.
  - Модальное окно легендарных исторических космических миссий (Восток-1, Аполлон-11, МКС, Вояджер-1, марсоход Кьюриосити).
  - Звуковое сопровождение интерфейса на Web Audio API с кнопкой отключения звука.
- **Автоматизация и тестирование:**
  - 22 модульных теста на базе Vitest v5 со 100% прохождением (PASS).
  - Непрерывная интеграция GitHub Actions CI (`.github/workflows/test.yml`) с проверкой типов, тестов и продакшен-сборки.

### 🐛 Исправлено (Fixed)
- **BR-01:** Предотвращено падение при переполнении дисковой квоты браузера через защищённую обертку `safeLocalStorageSet` с перехватом `QuotaExceededError`.
- **BR-02:** Устранено наложение карточки спутника на элементы управления временем на экранах смартфонов шириной менее 400px.
- **BR-03:** Ликвидирована утечка ресурсов видеопамяти при переключении вкладок браузера через корректное освобождение WebGL геометрий и текстур.
- **BR-04:** Исправлена ошибка неверной контрольной суммы для отрицательных коэффициентов в TLE-строках NORAD (знак минус `-` теперь корректно учитывается как единица).
- **NC-01..NC-05:** Устранены все «магические числа» и неименованные константы по результатам инспекции кода (День 11).

### ⚡ Изменено и оптимизировано (Changed)
- Размер сжатого бандла оптимизирован до **377.3 KB** (JS 369.6 KB, CSS 7.7 KB), что значительно меньше целевого лимита 500 KB.
- Время полной загрузки приложения составляет **1.28 секунды** (при целевом лимите ≤ 2.0 с).
- Плотность дефектов снижена до **0.76 багов на 1000 строк кода** (при отраслевом стандарте ≤ 5.0).
- Исходный код снабжен исчерпывающей JSDoc-документацией.

### 🛠 Стек технологий (Tech Stack)
- **Frontend Core:** React 19, TypeScript 5+, Vite 8, Tailwind CSS v4.
- **3D & Graphics:** Three.js r186, OrbitControls, EffectComposer, UnrealBloomPass.
- **Physics & Math:** `satellite.js` (SGP4/SDP4), кастомные астрономические формулы движения светил.
- **UI & Motion:** Lucide React (иконки), Motion (анимации), Canvas 2D (процедурные текстуры).
- **Backend / Proxy:** Node.js, Express, кэширующий шлюз к CelesTrak с отказоустойчивым Fallback.
- **Testing & Quality:** Vitest v5, TypeScript type-check (`tsc --noEmit`), GitHub Actions CI.
